# Otel Samba - Tamamen İşlevsel Rezervasyon Sistemi

<img width="414" height="706" alt="image" src="https://github.com/user-attachments/assets/84500f5b-4f90-4666-be19-13e0b9abb9e4" />

3 ayda sıfırdan geliştirdiğim, gerçek bir otel gibi çalışan rezervasyon sistemi.

## Özellikler
- Kullanıcı kayıt & giriş sistemi  
- Anlık fiyat hesaplama (hafta sonu + sezon zammı + oda özellikleri + ek hizmetler)  
- Promosyon kodu desteği  
- Müsait oda kontrolü & çakışma engelleme  
- Admin paneli (toplam gelir, en çok rezervasyon yapılan oda tipi)  
- Rezervasyon düzenleme & iptal  
- Renk kodlu doluluk takvimi (tek oda / tüm odalar)  
- Responsive + modern tasarım (Bootstrap 4 + custom CSS)  
- Tüm veriler localStorage'da tutuluyor (backend gerekmez)
